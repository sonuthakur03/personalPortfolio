## 🎨 Design Philosophy: B · Pop Brutalist

Moving away from cookie-cutter developer templates, this site is engineered using an authentic **Pop Brutalist** design system:
* **High-Contrast Geometry:** Solid 3px black borders (`border-[3px] border-[#111111]`) with bold color blocking.
* **Curated Pop Color Palette:**
  * Radiant Pink (`#FF6FB5`)
  * Electric Mint (`#7DFFA6`)
  * Cyber Yellow (`#FFE14D`)
  * Royal Soft Blue (`#7C9BFF`)
  * Warm Coral (`#FFB38A`)
  * Paper White (`#FFFFFF`) & Dark Obsidian (`#181A20` / `#0D0E12`)
* **Hard Offset Brutalist Drop Shadows:** Tactile zero-blur offsets (`shadow-brutal`: `4px 4px 0 #111111`, `shadow-brutal-md`: `6px 6px 0 #111111`, `shadow-brutal-lg`: `8px 8px 0 #111111`).
* **Tactile Micro-Interactions:** Physical button depression (`translate-y-0.5 active:shadow-none`), collectible sticker tilts, and animated state transitions.
* **Expressive Display Typography:** High-impact **Archivo Black** for display headers, paired with **Space Mono** for engineering telemetry and technical badges.

## 🚦 Getting Started

### Prerequisites
* **Node.js**: `v20.0.0` or higher (Recommended: Node 22 LTS)
* **npm**: `v10.0.0` or higher

### Installation & Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/sonuthakur03/personalPortfolio.git
   cd personalPortfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the local development server:**
   ```bash
   npm run dev
   ```
   Open [http://localhost:5173/](http://localhost:5173/) in your browser.

4. **Run the automated test suite:**
   ```bash
   npm run test
   ```
   Executes the 13 automated Vitest tests covering content accuracy, asset paths, safe link attributes, and component mount stability.

5. **Run type-checking and linter:**
   ```bash
   npm run lint
   npx tsc --noEmit
   ```

6. **Build for production:**
   ```bash
   npm run build
   ```
   Compiles optimized production assets into `dist/` with chunk splitting for instant initial paint.

7. **Preview the production bundle locally:**
   ```bash
   npm run preview
   ```

## 🔒 Security Protocols

This repository enforces strict engineering security standards:
1. **Zero Client Secret Leaks:** No private LLM API keys, database connection strings, or server tokens are ever bundled into client-side code.
2. **Reverse Tabnabbing Defense:** Every outbound link targeting `_blank` strictly specifies `rel="noopener noreferrer"`.
3. **Strict Content Security Policy (CSP):** Verified `script-src`, `font-src`, `frame-src`, and `connect-src` directives configured in `index.html`.
4. **XSS Mitigation:** Zero un-sanitized `dangerouslySetInnerHTML`.
5. **No Broken Links:** All profile links point to active, verified personal channels.
